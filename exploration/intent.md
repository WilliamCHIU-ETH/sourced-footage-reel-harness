# 來源層探索意圖

- 版本：v0.2
- 日期：2026-08-30
- 狀態：上游意圖與本輪執行授權已對齊；來源探索與最低可執行成片並行
- 範圍：來源層探索；不修改既有影片 harness

## v0.2 Decision Lock

- 本輪要決定：R-01（TechNews 選題再回溯第一方素材）與 R-02（第一方高素材密度 watchlist）能否各自形成可重複的來源路徑；至少用其中一條完成一支 canonical fresh-run 成片。
- 授權邊界：使用者已將本輪題材與素材挑選（原 GATE 1）委派給 orchestrator；達到最低可執行條件即試跑，不等待中途確認。
- 平行方式：來源深挖與成片驗證並行；成片不代表來源探索停止，也不代表產品效果或發佈權利成立。
- 人類 gate：唯一待使用者判斷的 gate 延後到來源探索、成片與 audit 全部完成後；屆時一次交付版本化結論 artifact 與影片供驗收（GATE 2）。
- 必要證據：可回查來源與素材 URL、題材與素材選擇理由、canonical fresh-run 命令／輸入／輸出／exit 狀態、視覺與機械 QA、reviewer findings、coverage gaps。
- 停止條件：至少一支由公開第一方素材完成且通過既有 harness 驗證的 fresh-run 成片，加上 R-01／R-02 的可執行性結論與下一個最小驗收；若所有候選都失敗，須交付逐一失敗證據，不以 agent 狀態代替。

## 問題

目前 harness 的影片產線已相對完整，但題材入口依賴人工放入的台股晨報 DOCX。這個入口同時有兩個風險：來源供應不穩定，以及題材範圍被綁在台股。量產不是本輪瓶頸；本輪要解的是如何由系統主動發現值得做、且能配到公開官方影片的題材。

## 預期成果

1. 建立可回查的來源地圖，涵蓋 CMoney 站內路徑、TechNews、TechNews 的上游來源，以及其他穩定提供官方影片的非科技題材來源。
2. 對每個來源記錄 URL 樣式、取用方式、更新頻率、登入需求、JS 渲染、RSS／API 狀態，以及「題材命中公開官方影片」的粗估與依據。
3. 以支持證據與反例檢驗假設：「有公開官方影片可用的題材，集中在科技突破／產品發表。」所有結論區分 confirmed、inferred、unknown。
4. 提出 1–2 條最值得持續的來源路徑，並由 orchestrator 直接選定最低可執行候選完成 fresh-run；最後一次性交付選擇理由、成片與未解風險。

## 受影響範圍

- 本輪新增文件僅限 `exploration/`。
- 本輪不修改 `SKILL.md`、`ASSUMPTIONS.md`、`bin/` 或既有產線行為。
- 來源研究與實作驗證可平行；下載、ffmpeg 與成片只能在指定 `run_dir`，並遵守每批不超過 5 項、`nice -n 19`、`OMP_THREAD_LIMIT=1` 與可見 pane 限制。
- 原 GATE 1 已由使用者明確委派給 orchestrator；GATE 2 保留，但延後到完整探索、成片與 audit artifact 一起交付時才由使用者判斷。

## 限制

1. `RECIPE.md` 只作歷史材料，不作本輪指令或題材答案。
2. YouTube 可用於確認官方影片存在，但現行環境匿名下載會失敗；可實際取得性優先查官方網站、newsroom、media kit 或企業影片平台。
3. websearch 唯讀，不登入、不註冊、不付款；任務書與產物不得含任何憑證。
4. 不使用任何付費影片生成、付費素材、登入、註冊或付款路徑；本輪試跑只沿用既有無影片生成費用的 harness 與公開可取得素材。
5. 每條關鍵結論必須回指 URL 與 2026-08-30 查核日期；缺乏直接證據時標示 inferred 或 unknown。
6. 不把欄目存在、搜尋命中或單一案例直接當成穩定供應；更新頻率與官方影片命中率必須揭露樣本與估算方法。
7. 本輪不得以產線效率或既有成片能力取代來源層驗證；成片成立只證明該候選可走通，不證明來源穩定性或外部發佈權利。

## Open questions

1. CMoney 站內哪些公開欄目能穩定提供非純價格、可獨立成片的技術／產品主張？是否存在公開 RSS 或 API？
2. TechNews 的欄目與 RSS 可否作為穩定選題入口；其內容抓取是否受 robots、JS 渲染或使用條款限制？
3. TechNews 的題材主要來自哪些上游：外電、原廠 newsroom、PR wire、官方 YouTube 或其他來源？哪些上游能更早且更穩定地取得題材與官方影片？
4. 科技突破／產品發表的官方影片命中率是否顯著高於其他類型？車廠、生技臨床、能源、航太國防、半導體設備、交易所或央行記者會等反例是否構成同等穩定的來源路徑？
5. 題材到官方影片的命中率應用何種小樣本定義與分母，才足以支持階段二選擇，而不製造虛假精準度？
6. 哪一個候選最先同時滿足「第一方公開素材可直接取得、足夠支撐 60 秒、題材事實可回查」而應被選為本輪 fresh-run？此判斷已委派給 orchestrator。
